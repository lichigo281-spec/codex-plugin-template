# Hello（示例技能）

这是一个最简单的示例技能，用来演示「技能 + MCP 工具」的配合方式。复制本目录并修改即可创建你自己的技能。

## 何时使用

- 用户说「打个招呼」「测试一下插件」之类的话。
- 用户询问现在几点、某个城市/时区的当前时间。

## 工作流程

1. 打招呼：调用 `my-toolkit` MCP 的 `hello` 工具，`name` 参数使用用户的称呼（未知时用「朋友」）。
2. 查时间：调用 `get_time` 工具。
   - 把城市名转换成 IANA 时区再传入 `timeZone`，例如：北京/上海 → `Asia/Shanghai`，东京 → `Asia/Tokyo`，纽约 → `America/New_York`，伦敦 → `Europe/London`。
   - 用户没有指定地点时不传 `timeZone`（使用本机时区）。
3. 把工具返回的结果用自然语言转述给用户。

## 约束

- 如果 MCP 工具不可用，告诉用户检查 Node.js（>=18）是否安装，以及插件 MCP 服务器是否启动成功，不要编造结果。

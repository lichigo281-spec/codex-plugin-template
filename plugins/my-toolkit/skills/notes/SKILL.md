# Notes（本地笔记技能）

通过 `my-toolkit` MCP 服务器在本机保存和读取简单的文字笔记。

## 何时使用

- 「帮我记一下……」「记个备忘」「加个待办」
- 「我之前记了什么？」「列出我的笔记」

## 工作流程

1. **保存**：调用 `notes_add`，`content` 为整理后的笔记内容。
   - 保留用户原意，可以补全明显省略的信息（例如把「明天」换算成具体日期，必要时先调用 `get_time` 获取今天日期）。
   - 一次请求包含多条事项时，逐条调用 `notes_add`。
2. **查看**：调用 `notes_list`，把结果整理成清晰的列表返回给用户；用户只关心某类内容时，自行筛选后再展示。
3. 保存成功后，简短告知用户笔记编号即可。

## 约束

- 不要在笔记里保存密码、密钥等敏感信息；如果用户要求，先提醒风险。
- 当前模板不支持删除/编辑笔记，用户提出时如实说明，并建议扩展 `mcp-server/server.mjs`。
